# 🎲 Dice Roller — Android

Aplicativo Android desenvolvido com **Kotlin e Jetpack Compose** que simula o lançamento de um dado de seis faces.

O projeto foi criado como exercício prático de desenvolvimento Android, com foco em gerenciamento de estado, interfaces declarativas e interação do usuário.

## Funcionalidades

- Sorteio aleatório de números de 1 a 6.
- Atualização da imagem conforme o resultado.
- Interface construída com Jetpack Compose.
- Dados personalizados com aparência 3D e acabamento azul brilhante.

## Tecnologias utilizadas

- Kotlin
- Jetpack Compose
- Android Studio
- Android SDK
- Gradle

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Selecione um emulador ou dispositivo Android.
5. Execute o aplicativo.

## Aprendizados

Durante o desenvolvimento, pratiquei:

- Criação de funções `@Composable`.
- Organização de componentes com `Column`.
- Utilização de `Image`, `Button` e `Spacer`.
- Gerenciamento de estado com `remember` e `mutableStateOf`.
- Estruturas condicionais com `when`.
- Utilização de recursos gráficos na pasta `drawable`.
